Open calls for the owner

1. Tab-row fit at 320px. "Quests · NPCs · Factions · Treasure" doesn't comfortably fit a 320px column at real tap-target size, so the tab row scrolls horizontally (try it above) rather than wrapping to a second row — a wrapped row would eat further into an already-tight vertical budget. Worth confirming that's an acceptable trade before real components; a genuinely narrower label set (e.g. "Quests / People / Factions / Loot") is a cheap alternative if the scroll reads as awkward once it's real.

2. Column header count. The header's right-side count (currently "N Quests") would need to become tab-aware — showing the active tab's count instead of always Quests' — or just drop the count entirely now that it's a shared header across four different lists. Not decided here.
